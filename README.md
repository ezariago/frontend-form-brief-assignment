# Project Request Form

A simple one-page frontend form built with Next.js, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

The form checks that the name, email, project type, and description are filled in correctly. After submission, it shows a confirmation message. This is a frontend-only project, so the form does not send data to a server.

## Checks

```bash
npm run lint
npm run build
```
